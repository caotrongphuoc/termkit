# termkit

My bash terminal setup for Linux. Edit a config file, run one command.

## Quickstart

1. Clone this repo somewhere you plan to keep it (the paths written to `~/.bashrc` are absolute).
2. Open `configs/settings.conf` and change what you want.
3. Run `./install.sh apply`.
4. Open a new terminal, or `source ~/.bashrc` in the current one.

To undo everything: `./install.sh uninstall`.

## Commands

```
./install.sh apply       read settings.conf and apply to ~/.bashrc
./install.sh status      show current settings.conf values
./install.sh clean       reset settings.conf to defaults (old file kept as .bak)
./install.sh uninstall   remove termkit changes from ~/.bashrc
./install.sh             print usage
```

## Layout

```
termkit/
├── install.sh
└── configs/
    ├── settings.conf      # state file: your picks live here
    ├── themes/*.conf      # each defines PS1 and shell colors
    ├── fonts/*.ttf        # copied to ~/.local/share/fonts when install=true
    ├── logo/*.txt         # printed on shell start when enabled
    └── aliases.sh         # sourced when aliases are enabled
```

## settings.conf schema

```
[theme]
name=default              # basename of a file in configs/themes/*.conf

[font]
name=none                 # basename of a file in configs/fonts/*.ttf, or none
install=false             # copy the .ttf to ~/.local/share/fonts and refresh cache

[logo]
enabled=false             # print the logo on shell start
file=none                 # basename of a file in configs/logo/*.txt

[aliases]
enabled=false             # source configs/aliases.sh on shell start
```

## What apply does to your bashrc

- On the first run, `~/.bashrc` is copied to `~/.bashrc.termkit.bak`.
- A managed block is appended:

  ```
  # >>> termkit start >>>
  # Generated by termkit. Do not edit by hand.
  source "/absolute/path/to/configs/themes/default.conf"
  cat "/absolute/path/to/configs/logo/tux.txt"
  source "/absolute/path/to/configs/aliases.sh"
  # <<< termkit end <<<
  ```

- Re-running `apply` strips the old block and writes a new one — never stacks a second one.
- If `[font] install=true`, the `.ttf` is copied to `~/.local/share/fonts/` and `fc-cache -f` runs.
- Anything else in your `~/.bashrc` is left alone.

## Adding your own theme, font, or logo

- **Theme**: drop `mytheme.conf` into `configs/themes/`. Inside, set `PS1`, `LS_COLORS`, or anything you want every new shell to run. Then set `[theme] name=mytheme` in `settings.conf` and run apply.
- **Font**: drop `MyFont.ttf` into `configs/fonts/`. Set `[font] name=MyFont` and `install=true`.
- **Logo**: drop `mylogo.txt` into `configs/logo/`. Set `[logo] file=mylogo` and `enabled=true`.

## Uninstall

`./install.sh uninstall`:

- Removes the managed block from `~/.bashrc` (rest of the file is untouched).
- Removes any file under `~/.local/share/fonts/` whose basename matches one in `configs/fonts/`. Fonts you installed from other sources are not touched.

The `~/.bashrc.termkit.bak` backup is kept. To fully revert to the original bashrc:

```
cp ~/.bashrc.termkit.bak ~/.bashrc
```

## Requirements

Bash, plus standard tools: `awk`, `sed`, `mktemp`, `cp`, `mv`. `fc-cache` is only needed if you install a font. Linux only.
